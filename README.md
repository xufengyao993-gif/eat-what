# 今天吃啥 🍚（上海）

纠结「中午吃啥」的时候，帮你把这个决定做掉，再直接找到店。

纯静态网页，没有后端、没有构建步骤、不上传任何数据 —— 自定义菜单、吃饭记录、地图 Key 都只存在你自己的浏览器里（localStorage）。

## 功能

**决定吃什么**

- **一键抽菜**：老虎机式滚动动画，抽完直接给结果，不再给你第二个选择题
- **一步步帮我选**：按「预算 → 菜系 → 口味 → 地点」逐步收窄，**每个选项都实时显示选了还剩几道菜**，会选空的选项直接标灰，不会走到最后才发现没得选。前三步都能多选，所以不会点一下就自动翻页 —— 选过之后底部按钮会变成醒目的「下一步」，也可以左右滑动翻页
- **快速筛选**：不想走流程就直接在筛选面板里点，两种方式共用一套条件
- **不重样**：默认对最近吃过的菜降权（当天 5%、3 天内 30%、7 天内 60%），避免一周吃五顿黄焖鸡
- **换一个**：对结果不满意，再抽必定换一道
- **130 道菜**，含本帮沪菜和上海面点小吃（生煎、小笼、葱油拌面、辣肉面、蟹黄拌面…）

**决定去哪吃**

- **一键跳到点评 / 高德 / 美团**：带着「菜名 + 你选的商圈」直接打开对方的搜索结果页，手机上会尝试唤起 App。零配置
- **附近餐厅**（选填高德 Key）：在应用里直接看附近店的评分、人均、距离和推荐菜
- **怎么过去**：点开某家店，显示从你的位置（或所选商圈）走路 / 骑车 / 开车各要多久、多远。按需查询，不会为整个列表消耗配额
- **地点**：定位「我附近」，或从 24 个上海常用商圈里选一个

**其他**

- **自己的菜单**：每道菜都能编辑和删除 —— 改名字、分类、餐别，还能记下**店名、位置、评分和评价**。记过店的菜，抽到时会把你的笔记显示出来，跳点评时也直接搜这家店而不是搜菜名
- **加自己的菜**：「巨鹿路那家生煎」这种只有你知道的选项
- **吃饭记录**：点「就吃这个」记一笔，能看最近 7 天吃了几顿、最常吃什么
- **摇一摇**：手机摇一下就抽（iOS 需要先点一次授权）
- **分享给朋友**：顶栏 🔗，手机上调系统分享面板，桌面上复制链接
- **深浅色主题**，可「添加到主屏幕」当 App 用

## 关于接入大众点评 / 美团 / 高德

先说结论：**点评和美团没有个人开发者能自助申请的接口**。它们的开放平台走「联系商务申请」路径，面向的是给商家做 SaaS 的服务商，要企业资质和签约。所以本项目对这两家用的是**跳转**方案 —— 拼好搜索词打开它们的搜索结果页，商家信息、评分、评价由它们自己展示。这不需要任何 key，也不受接口政策变化影响。

**高德是唯一对个人开放的**，可以免费申请 Key，在应用内直接列出附近餐厅。

| 方式 | 需要什么 | 能拿到什么 |
| --- | --- | --- |
| 跳大众点评 | 不需要 | 点评的完整搜索结果（评分、评价、团购） |
| 跳高德地图 | 不需要 | 高德的地图搜索结果，可直接导航 |
| 跳美团 | 不需要 | 美团的搜索结果 |
| 应用内附近餐厅 | 高德 Key（免费） | 店名、评分、人均、距离、地址、推荐菜 |

### 能不能跳到手机 App

分环境，代码里按 UA 自动选：

| 环境 | 怎么跳 | 能不能进 App |
| --- | --- | --- |
| Android 浏览器 | `intent://`，内嵌 `browser_fallback_url` | 装了就进 App，没装自动跳网页版 |
| iOS Safari | `dianping://` / `imeituan://`，1.5 秒没反应跳网页版 | 装了一般能进，会先弹一个「打开"大众点评"？」的确认框 |
| **微信内置浏览器** | **只跳网页版** | **进不去** |

微信会拦截所有第三方 App 的 scheme 和 intent 跳转，这是微信的限制，绕不过去（能绕的都是走应用宝之类的灰色路子）。所以在微信里点这三个按钮，会先提示「右上角「···」→ 在浏览器打开」，然后跳到对方网页版。

因为你主要是在微信里分享，这条要提前跟朋友讲一句：**想直接进 App，得先用系统浏览器打开这个网站**（微信右上角「···」→ 在浏览器打开），然后「添加到主屏幕」，以后从桌面图标进就没这问题了。

跳过去搜得不准的时候，结果区有个「复制菜名」，复制了自己在 App 里搜也行。

### 配高德 Key

1. 去 [高德开放平台](https://lbs.amap.com/) 注册（个人即可），实名认证
2. 创建应用 → 添加 Key → **平台类型选「Web端 (JS API)」**
3. 把 Key 和随之生成的**安全密钥 securityJsCode** 一起填进 App 右上角 ⚙️

用的是 JS API 的 `AMap.PlaceSearch` 插件，不是 Web 服务 API —— 后者不允许浏览器跨域直接调用，纯静态站点用不了。另外高德的「搜索POI 2.0」高级接口面向企业试用，个人用的是常规 PlaceSearch。

> ⚠️ 三个跳转链接的格式（在 `assets/data.js` 的 `PLATFORMS` 里）是按各家公开的 URL / URI Scheme 规则拼的，但**开发时的网络环境访问不到这些站点，没能实测**。第一次用请在手机上点一下确认；哪个失效了，改 `PLATFORMS` 里对应的一行即可。

## 本地跑起来

直接双击 `index.html` 就能用。想更接近真机环境：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 分享给朋友用

部署好之后把网址发出去就行，各人的菜单和记录存在各自手机上，互不影响。两点要注意：

- **github.io 在国内移动网络下经常访问不稳定**。发出去之前先用手机流量（不是 WiFi）自己开一次。打不开的话得换国内能稳定访问的静态托管。
- **「附近餐厅」需要每人自己填高德 Key**，朋友基本不会去申请。所以给别人用时，默认体验是「抽菜 + 跳转到点评/高德/美团」，这条路径零配置、开箱即用。想让所有人都能用应用内的附近搜索，得把 Key 内置到代码里（配合严格的域名白名单）。

## 部署到 GitHub Pages

仓库 **Settings → Pages → Source** 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后等一两分钟，就能通过
`https://<你的用户名>.github.io/eat-what/` 访问，手机扫码就能用。

## 我的记录存在哪

- 自己加的菜 → `ew.custom`
- 对默认菜的修改（改名、店名、评价…）→ `ew.edits`，单独存一份盖在默认菜上，所以以后更新菜品库不会冲掉你改的东西
- 删掉的默认菜 → `ew.deleted`，「恢复默认」可以找回
- 取消勾选的菜 → `ew.off`
- 吃饭记录 → `ew.history`

全都在浏览器 localStorage 里。**关浏览器、重启手机不会丢**，但下面这些情况会：

| 情况 | 会不会丢 |
| --- | --- |
| 关浏览器 / 重启手机 | 不丢 |
| 清除浏览器缓存、网站数据 | 丢 |
| 换手机、换浏览器 | 丢 |
| 无痕模式 | 一关就丢 |
| iPhone + Safari，超过 7 天没打开 | 可能被自动清掉 |

最后一条是 Safari 的隐私机制会清理长期未访问网站的本地存储。**把网页「添加到主屏幕」，从桌面图标进就能避开这条**，顺带没有地址栏更像 App。

### 备份

设置 ⚙️ 里有「备份与恢复」：

- **复制备份** —— 导出成一段 JSON 文本，粘到微信收藏或备忘录里就存住了，微信里也能用
- **存成文件** —— 下载 `eat-what-backup-日期.json`
- **恢复** —— 把文本粘回去，或者选文件导入

导入会**覆盖**当前设备上的内容，动手前会先问一次，并告诉你这份备份里有多少条记录。文件格式是普通 JSON，自己看得懂也改得动。

## 改菜单

菜品都在 `assets/data.js` 的 `DEFAULT_DISHES` 里，格式：

```js
{ n: '重庆小面', e: '🌶️', c: '面食', m: 'bld', p: 1, s: 2, v: false }
```

| 字段 | 含义 |
| --- | --- |
| `n` | 名称 |
| `e` | emoji |
| `c` | 分类，必须是 `CATEGORIES` 里的一项 |
| `m` | 适合的餐别，`b`早 `l`午 `d`晚 `n`夜宵，可组合 |
| `p` | 价位：1 便宜（20 以内）／2 适中（20–50）／3 小贵（50 以上） |
| `s` | 辣度：0 不辣／1 微辣／2 够辣 |
| `v` | 是否清淡、素食友好 |

改完刷新即可。只是想加自己常吃的几家店的话，不用改代码，在 App 的「菜单」页直接加。

## 之后想做成小程序

现在这版是移动端网页，先跑起来验证玩法。要上小程序有两条路：

1. **webview 套壳**（最快）：小程序里放一个 `<web-view src="你的 Pages 地址">`，需要一个已备案域名并在小程序后台配置业务域名。
2. **改成原生小程序**（体验更好）：`assets/data.js` 可以原样复制进小程序当数据源，筛选和加权抽取的逻辑（`pool()` / `weightOf()` / `pickFrom()`）也能直接搬，只需把 DOM 渲染换成 WXML + `setData`，`localStorage` 换成 `wx.getStorageSync` / `wx.setStorageSync`。核心逻辑和界面是分开写的，这一步不算大改。

原生版还能顺带做网页做不了的事：分享给朋友让他帮你抽、多人一起投票选餐厅。

## 改商圈 / 换城市

商圈列表在 `assets/data.js` 的 `AREAS`，坐标是高德坐标系（GCJ-02）的「经度,纬度」。
换城市改 `CITY`：`name` 是高德搜索用的城市名，`dianpingId` 是大众点评的城市编号（上海 1、北京 2、广州 4、深圳 7、杭州 3）。

## 已知限制

- 定位优先用高德的 `AMap.Geolocation`，它返回 GCJ-02，跟高德的 POI 坐标对得上。没填 Key 时退回浏览器定位，那是 WGS-84，市区内会偏几百米，界面上会标注出来。
- 搜索中心取决于「筛选条件 → 地点」：选「我附近」用定位结果，选商圈用该商圈坐标，选「还没定」则不限定中心、按全城搜，此时距离没有参考意义。
- 「附近餐厅」里的推荐菜取自高德 POI 的 tag 字段，不是每家店都有。

```
assets/
  data.js               菜品库、上海商圈、平台跳转链接
  app.js                主逻辑（引导流程、筛选、加权抽取、菜单、记录）

  icon-192.png / icon-512.png / icon-maskable-512.png
```
